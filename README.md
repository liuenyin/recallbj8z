# 八中重开模拟器

This contains everything you need to run your app locally.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

游戏默认使用仓库内的离线事件。可以在首页或游戏内的「更多」切换语言，两种语言共用路线和存档。

Select **English** on the home screen or under **More** in the game. Both languages use the same routes and local saves. The built-in events and their translations come with the game and work without an API key.

## AI 事件模式

在首页底部打开「AI 模式」，填写兼容 Chat Completions 的接口、模型名称和 API Key，再测试并保存。没有主线或支线事件时，游戏会按当前语言请求一批事件并展示第一条。请求失败时使用离线事件。

配置保存在当前浏览器的 `localStorage`，不会写入游戏存档。由于浏览器会直接向你填写的地址发送 API Key，请只使用可信的 API 服务和设备，并确认该服务允许浏览器跨域请求。

常见地址示例：

- DeepSeek：`https://api.deepseek.com/chat/completions`
- OpenAI：`https://api.openai.com/v1/chat/completions`
- 其他兼容服务：填写其完整的 `/chat/completions` 地址，或填写服务根地址让游戏自动补全路径。

AI 请求默认 30 秒超时；服务端返回 5xx 时会自动重试一次。生成结果会被限制在 2-3 个事件、每个事件 2-4 个选项和受控数值范围内，不符合格式时自动回退离线事件。

## 难度与兴奋值

游戏提供普通、困难、现实三档预设和自定义开局。难度影响开局学科基础、排名、学习收益、疲劳增长和休息效果。

文化课考试的满分按现行选科组合计算：语文、数学、英语各 150 分，三门选考科目各 100 分，合计 **750 分**。系统会按实际考试科目去重计算上限，存档中的非法或重复选科不会把总分改成其他数值。

现实难度显示余额和考试成绩，其他属性以体感呈现。心态低于 20 或疲劳超过 90 时需要先休息再学习。750 分制的模拟年级均分约为 600。旧地狱存档读取后转为现实难度。

兴奋值是一个 0-100 的短期资源。兴奋越高，学习和体育的正收益越高，但补觉和休息的疲劳恢复越弱；看电影、运动、游戏、AI 事件和小卖部的兴奋剂都可能改变它。每周结算会让兴奋逐步回落到正常水平。

连续透支、兴奋过高或长期低落会进入轻量状态，并在个人档案中显示。部分选择会留下不立即结算的后果，例如侥幸抄作业可能在数周后遇到抽查。健康或疲劳接近危险线时，界面会用暗色和红色边缘提示；恋爱状态则会让背景变暖，但这些提示不会遮挡事件和操作。

同一周重复安排同一活动时，第二次起正向收益会递减，负面代价保持不变。执行周计划后，日志会自动生成一条精简总结，方便回看本周安排。

开发时可运行 `npm run test:balance` 回归重复收益和基础数值边界。

## 本地账号与存档

主页的“账号与存档”用于在同一浏览器中创建多个本地档案。每个账号都有独立的游戏进度，可以随时切换或删除（游客档案不会删除）。账号名称和进度只写入当前设备的 `localStorage`，不提供服务器登录、密码安全或跨设备同步；需要这些能力时应接入独立后端服务。

## 竞赛路线

暑假的主攻方向现在包含 OI 和数学竞赛（MO）。OI 路线有校内信息学教练和同学训练小组，也能参加外校专题课、线上赛和跨校模拟赛，并体验公开赛出题、验题和上线后的反馈。省选、APIO 等后续机会同时参考 NOIP 成绩和持续训练记录。

MO 路线从暑假训练开始。游戏里的教练在高一上确认参赛资格，已确认的学生可在 9 月参加个人联赛。周末可以练一试限时题或轮换做二试的几何、代数、数论和组合证明。高一下安排校内模拟，同样按一试 120 分、二试 180 分计分。结算单独保留两场考试的成绩。校内训练和赛区获奖判定为游戏设定，各年实际赛区奖项以官方公告为准。

## 开发检查

建议使用 Node.js 22.18 或更新版本，并用 `npm ci` 按锁定文件安装依赖。

- `npm run check`：依次执行类型检查、全部单元/回归测试、生产构建。
- `npm run dev`：启动开发服务。
- 开发服务运行后，在另一个终端执行 `npm run test:browser`：使用独立临时浏览器档案，屏蔽外部请求，检查移动布局、账号、新游戏、异常存档和 AI 响应边界。需要安装 Chrome/Chromium/Edge；非默认位置可设置 `CHROME_PATH`，自定义开发地址可设置 `SMOKE_URL`。该测试需要 Vite 开发服务，以测试实际 AI 模块。
- `npm audit`：检查依赖数据库当前报告的已知漏洞。

Tailwind 样式和 Font Awesome 图标现在在构建阶段打包，不再从 CDN 加载。默认使用系统中文字体。赞助头像等外部内容仍需要网络；启用 AI 模式也需要网络。

本次代码审查、修复和后续改进优先级见 [项目审查报告](PROJECT_REVIEW.md)。

## 操作小贴士

周末直接打开时间表，也可以采用推荐安排。上课周的周一到周四晚固定晚自习，周五可在高一上第 2 周报名。第 3 周可以选一至两门三修课，分别占用周六上午和下午。每个上课周需要安排两到三个时段写作业。平时可通过游戏内的「更多」打开时间表。

游戏中或结局页打开历程，可以在“校园手记”中点击“导出这段经历”，保存一份按时间顺序排列的文字手记。

事件和周计划结算到稳定节点时，会自动保存到当前本地账号；结局也会保存。页面上方显示保存时间或失败提示，仍可手动点击“保存”。尚未结束的事件、选科和考试不会覆盖上一个稳定存档。

“保存”会另外保留一份独立手动存档，自动保存不会覆盖它。首页或游戏上方可“读取手动存档”；“继续游戏”读取最近进度。每个本地账号各保留一份手动存档，再次手动保存才会替换。新开局也不会删除这份手动留档。

日常事件的自动继续可在游戏上方关闭，也可在反馈页点“改为手动继续，等我看完”；偏好会保留在当前浏览器。查看手记等弹窗时会暂停计时。周末结算会显示完成、跳过数量和主要属性净变化，展开即可查看每个时间段的结果与跳过原因。“泡图书馆”已合并到“上图书馆”，旧计划自动转换。

离线日常事件已整理为 18 个短场景，替换原来的大批重复生成文本。日常选择的反馈会停留片刻后自动继续，重要剧情仍需要确认；反馈也会记录在校园手记里。班级板报现在有交稿提醒和同学回访，会记得你负责画画还是找素材。
