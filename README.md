# 八中重开模拟器

This contains everything you need to run your app locally.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

游戏默认使用仓库内的离线事件数据，不需要 API 密钥。只有运行 `scripts/generate_events.js` 扩充事件时，才需要在服务端环境变量中设置 `DEEPSEEK_API_KEY`；不要把密钥写入前端代码或提交到仓库。

## AI 事件模式

主页点击“AI 模式设置”，填写一个 OpenAI 兼容的 Chat Completions 接口、模型名称和 API Key，测试连接后保存并开启即可。每周没有固定事件或支线事件时，游戏会根据当前属性和近期经历请求 2-3 个新事件；请求失败会自动回退到离线事件，不会卡住游戏。

配置保存在当前浏览器的 `localStorage`，不会写入游戏存档。由于浏览器会直接向你填写的地址发送 API Key，请只使用可信的 API 服务和设备，并确认该服务允许浏览器跨域请求。

常见地址示例：

- DeepSeek：`https://api.deepseek.com/chat/completions`
- OpenAI：`https://api.openai.com/v1/chat/completions`
- 其他兼容服务：填写其完整的 `/chat/completions` 地址，或填写服务根地址让游戏自动补全路径。

AI 请求默认 30 秒超时；服务端返回 5xx 时会自动重试一次。生成结果会被限制在 2-3 个事件、每个事件 2-4 个选项和受控数值范围内，不符合格式时自动回退离线事件。

## 难度与兴奋值

游戏提供普通、困难、现实、地狱四档预设。难度会同时影响开局学科基础、同学平均水平、课堂效率、疲劳增长和休息效果；地狱难度下每周最多安排一次学习型周末活动。

地狱难度的额外规则是：健康低于 10 会立即结束，心态低于 20 或疲劳超过 90 时学习选项不可用；学习效率和学习正收益按 2/3 计算，同学平均水平更高，小卖部价格翻倍，开局天赋点为 -1，必须用负面天赋补足后才能开始。

兴奋值是一个 0-100 的短期资源。兴奋越高，学习和体育的正收益越高，但补觉和休息的疲劳恢复越弱；看电影、运动、游戏、AI 事件和小卖部的兴奋剂都可能改变它。每周结算会让兴奋逐步回落到正常水平。

连续透支、兴奋过高或长期低落会进入轻量状态，并在个人档案中显示。部分选择会留下不立即结算的后果，例如侥幸抄作业可能在数周后遇到抽查。健康或疲劳接近危险线时，界面会用暗色和红色边缘提示；恋爱状态则会让背景变暖，但这些提示不会遮挡事件和操作。

同一周重复安排同一活动时，第二次起正向收益会递减，负面代价保持不变。执行周计划后，日志会自动生成一条精简总结，方便回看本周安排。

开发时可运行 `npm run test:balance` 回归重复收益和基础数值边界。

## 本地账号与存档

主页的“账号与存档”用于在同一浏览器中创建多个本地档案。每个账号都有独立的游戏进度，可以随时切换或删除（游客档案不会删除）。账号名称和进度只写入当前设备的 `localStorage`，不提供服务器登录、密码安全或跨设备同步；需要这些能力时应接入独立后端服务。

## 竞赛路线

暑假的主攻方向现在包含 OI 和数学竞赛（MO）。OI 路线按八中校内竞赛资源有限的背景设计：没有默认的成熟校队和固定教练，路线会从自发训练小组延伸到外校集训、线上社区、跨校模拟赛、公开赛出题、验题、上线和赛后反馈。省选、APIO 等后续机会同时参考 NOIP 成绩和持续训练记录，避免一次偶然高分直接跳到高阶结算。MO 路线则包含训练课、解题小组、命题组邀请、证明审稿和数学竞赛决赛。两条路线共用现有学科、经验、心态和周末计划系统，不额外引入一套独立资源；对应的路线事件会根据选择和前置结果逐步出现。

MO 路线在周末计划中提供“数学竞赛训练”，收益集中在数学和经验，同时会消耗少量心态并按学习活动规则受到疲劳、难度和重复安排的影响。学年结算会根据 MO 获奖、命题经历和竞赛参与情况给出不同叙述。
